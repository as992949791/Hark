## 业务链路与 Jev 的实际位置

新项目 → 后台读取网站、建立画像与搜索计划 → 首次历史回填 → 定时更新 → 判断并排序线索 → 人工到原平台处理 → 告警/研究/API。

1. 创建请求只写项目并排队。`discovery_initial` 在后台读站点、生成画像/brief、发现来源和安排 backfill 等任务。首页“一分钟”是宣传预期，不是验收时限。[src/lib/discovery/initial.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/lib/discovery/initial.ts)、[src/lib/profile.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/lib/profile.ts)、[src/lib/brief.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/lib/brief.ts)。
2. AnyAPI 提供网站读取、Google 搜索、Reddit 帖子/评论/作者/社区及可选 X 数据。检索/初筛后再读取值得看的线程，存储和复用结果。[src/lib/anyapi.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/lib/anyapi.ts)、[src/lib/scan/run.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/lib/scan/run.ts)、[src/lib/scan/retrieve.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/lib/scan/retrieve.ts)、[src/lib/reddit/fetch.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/lib/reddit/fetch.ts)。
3. Jev 接受状态和问题，输出 `noul/choice/score` 结构化答案，自身不生成文案。配置 Gateway 时先走 Gateway，符合回退条件才走 OpenRouter；没有 Gateway 配置则用 OpenRouter Decisions endpoint。[src/lib/jev.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/lib/jev.ts)、[src/lib/scan/questions.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/lib/scan/questions.ts)。
4. 当前评分包含产品无关阅读、产品适配、需求状态、买家关系及训练系数模型；明确卖家/帮助别人/需求已解决等先被排除，质量阈值和证据不足决定是否复核。合格判定与 feed 排序是不同步骤。[src/lib/scan/leadModel.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/lib/scan/leadModel.ts)、[src/lib/scan/gates.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/lib/scan/gates.ts)、[src/lib/scoring/weights.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/lib/scoring/weights.ts)。
5. 画像、发现、聚类等还有生成式模型调用，评分理由/证据由下游逻辑组织。因此仅配置 Jev 不能跑通原仓库全部功能。基线阶段保留原版 Jev + 生成式模型链路，不先做替换。[src/lib/llm.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/lib/llm.ts)、[src/lib/scan/report.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/lib/scan/report.ts)。
6. 调度采用 Cron + PostgreSQL jobs、领取/租约/状态更新，包含 scan、backfill、discovery、rescore、insights、competitor_scan、seo_refresh、digest、retention；X 按开关运行。[src/instrumentation.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/instrumentation.ts)、[src/jobs/scheduler.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/jobs/scheduler.ts)、[src/jobs/runner.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/jobs/runner.ts)、[src/jobs/registry.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/jobs/registry.ts)。
7. Drizzle + PostgreSQL 保存共享采集数据及项目、线索、评估、消费、任务、X 数据。[src/db/schema/shared.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/db/schema/shared.ts)、[src/db/schema/tenant.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/db/schema/tenant.ts)、[src/db/schema/x.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/db/schema/x.ts)、[src/db/schema/competitors.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/db/schema/competitors.ts)。

原版不自动评论或私信、不代写回复、不用“不匹配”反馈悄悄修改过滤规则。复刻基线保留这些行为。

## REST 与 MCP

REST 为只读 GET：`/api/v1/me`、`/api/v1/projects`、`/api/v1/projects/{id}`，以及项目下 `/leads`、`/seo-opportunities`、`/pain-themes`、`/usage`。[public/openapi.json](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/public/openapi.json)、[src/lib/api/handlers.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/lib/api/handlers.ts)。

MCP 为 `/api/mcp`，工具 `list_projects`、`list_leads`、`get_lead`、`list_seo_opportunities`、`list_pain_themes`、`get_usage`、`describe`。[src/lib/api/mcpTools.ts](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/src/lib/api/mcpTools.ts)。它们主要描述 Reddit 的只读结果，不能假设 X 有同样的 API。

## 后续运行约束

技术栈来自固定提交 [package.json](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/package.json)：Next 16.3.4、React 19.2.3、TS 5.9.3、Tailwind 4.3.3、Base UI 1.8.0、Drizzle 0.45.2、Clerk 7.9.1。AnyAPI SDK 是 `^0.46.2`，实际安装遵循 [package-lock.json](https://github.com/getanyapi-com/lurk/blob/44834c83b8aa34f46f17b93806aa1588240d855e/package-lock.json)。

| 项目 | 下一阶段准备/验证 |
|---|---|
| 本机 | Node v24.20.0 / npm 11.19.0 可用；本次 PATH 没找到 Docker，下一步检查 Docker Desktop 或本地 Postgres 路线 |
| 数据库 | Compose 使用 PostgreSQL 17；主机端口 5433，应用 3000；配置 DATABASE_URL、执行迁移 |
| 认证 | 自有 Clerk 应用与公开/服务端密钥，不用原站密钥，不绕过认证 |
| 数据/模型 | AnyAPI key；OpenRouter key 可覆盖原版 Jev 和生成式调用；Gateway 为可选 Jev 路径。实际可用性在接入阶段验证 |
| 应用 | APP_URL、32 字节 base64 APP_ENCRYPTION_KEY；密钥放环境配置 |
| 调度 | `.env.example` 显式 `RUN_SCHEDULER=false`；Compose 仅未设置变量时默认 true，直接复制示例不会自动开启调度 |
| 模式 | `SELF_HOSTED=true` 去除应用套餐限制，外部 API 仍收费、鉴权仍保留；free/connected 需另测额度界面 |
| X | `X_LEADS=false` 默认；复现 X 功能要显式开启；`X_REPLIES=true` 默认 |
| 费用 | 示例 house data 50 USD/日、LLM 10 USD/日；config schema 的 LLM 缺省 100、Compose 缺省 10。后续真实扫描先明确预算，不能把缺省上限当用户授权消费金额 |
| 通知 | 邮件 From + Azure 或 SMTP；Slack/Discord 可粘贴 webhook，OAuth 安装还需平台应用与回调 |
| 钱包 | 用户钱包连接需 AnyAPI OAuth client 和一致的 APP_URL 回调；先用自己的 house key 验证基础链路 |
