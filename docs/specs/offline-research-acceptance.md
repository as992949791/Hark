Exact quotation checks are not semantic correctness, recall or web-source incremental value.
4. Run the tool against the existing private CapCut snapshot; keep source text, identities and judgements out of Git. Do not invent labels or certify the incomplete human target. Record source reuse and actual sample count.
5. Run appropriate checks, independent Standards/Spec review, full verification and GitHub commit/tag archive. Keep #17/#20 open for actual fresh-source/human/public acceptance. Verify prior completed tooling subissues and archive before closing the stale #1 parent.

No new dependencies, schema, UI redesign, production activation/deployment, paid model/data requests, wallet or external messages. Existing software and fixtures do not substitute for fresh-platform searches, external mailbox receipt, cross-day observation, human relevance labels or customer feedback.
