# Issue tracker

Hark work is tracked in GitHub Issues at https://github.com/as992949791/Hark.
Read the issue and its dependencies before implementing it. Specs link to their tickets; ticket bodies declare blocking issues. Publish tickets in dependency order. Use the configured role labels in triage-labels.md. Resolve a ticket only after its acceptance criteria are verified and its implementation is archived. PRs as an incoming request surface: off.
