# ADR-0004: Own demand research independently from product projects

Accepted for the planned implementation on 2026-10-17; not yet implemented. A demand run belongs directly to its signed-in owner and optionally references an owned product project. Topic mode requires no fake product and makes no product-fit claim. This keeps the existing product profile/scanning model intact while serving people researching a need before they have a product.

New evidence and run/job associations remain separate from existing Reddit-only SERP storage and product retrieval plans. Topic costs must enter the existing daily accounting through an explicit run reference: permit a project-less data-ledger row only with that reference, and retain a minimal billing record after evidence expiry. Reusing null-project enqueue coalescing or treating a topic as a normal product would incorrectly mix ownership, work and spend. The foundation release must verify the migration constraints, exact-job owner admission and existing project behavior before adding provider calls.
